# Product Catalogue Verification

Verify each commercial product identity, active offer status, permitted pricing, implementation charge, cost basis, margin floor and fulfilment definition against canonical source records. Reject stale, missing, mismatched or static fallback prices; never publish or offer unverified terms. Preserve product, tenant and evidence provenance.

## Evidence contract

Return canonical evidence references, observation time, identity, what is verified, what remains unknown and explicit validation steps. A green check or queue completion is not revenue evidence.

## Execution authority

This skill provides advisory instructions only. Execution authority remains **none**; all live contact, binding terms, payments, fulfilment, production changes and revenue recognition require independent existing EmpireOS gates.
