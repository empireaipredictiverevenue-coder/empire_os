## Data / intelligence distribution channels

### Neudata
Strongest specialist channel for financial / private-market intelligence.
- 1,000+ qualified data buyers.
- Free provider listing.
- Buyer/seller matchmaking via AltDating.
- Particularly relevant to Private Capital, Property, Market, Search-demand and
  physical intelligence datasets.

### Snowflake Marketplace
Strong channel for structured enterprise data products and live shared data.
- Paid listings supported.
- Useful for Permit, Property, Search, Market and Predictive Revenue feature feeds.

### Databricks Marketplace
Strong channel for data + AI products.
- Supports datasets, models, notebooks, apps and MCP servers.
- Commercialised data offerings supported.
- Very relevant to Empire Search Fabric APIs, intelligence MCP, models and feeds.

### AWS Data Exchange / AWS Marketplace
Large enterprise distribution channel.
- Third-party data products and APIs.
- Provider registration / eligibility required.
- Useful after Empire has packaged repeatable datasets and support process.

### Google BigQuery sharing / Cloud Marketplace
Commercial BigQuery datasets can be published and monetized.
- Useful for enterprise buyers already living in Google Cloud.

### BattleFin
High-touch alternative-data buyer matchmaking.
- More expensive than marketplace listings.
- Use only after one or more institutional-grade data products have proven signal.

## Distribution rule

Do not put raw scraped contact/person data into marketplaces.

Package:
- aggregated / entity-safe opportunity signals;
- market/corridor intelligence;
- permit/property intelligence;
- search / demand observations;
- storm / physical signals;
- company / sector features;
- APIs / MCP tools;
- forecast-ready features with provenance.
