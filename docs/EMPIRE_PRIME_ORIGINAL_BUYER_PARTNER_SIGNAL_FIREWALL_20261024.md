# EmpireOS PRIME — Original Partner Signal Promotion Firewall

24 October 2026 | Original Predictive Cloud / Buyer Acquisition | Research branch | Production HOLD

## Why this was added

Partner correspondence about routing, pilot preparation, contracting or declined onboarding is real-world commercial activity, but it is not a verified consumer buyer enquiry, payable call, signed agreement or realised revenue. PRIME must preserve these distinct statuses and their negative evidence.

The pure module empire_os/prime_buyer_partner_signal_shadow.py accepts only bounded original-owner event-code metadata and rejects raw email fields, unknown event codes, direction mismatches, future timestamps and duplicate message/code occurrences. It has no live mail reader, database connection, model or execution rights. It outputs internal category counts and a separate privacy-coarsened Founder projection, suppressing category counts below five.

## Source-owner code mappings

- ROUTE_OR_NUMBER_LIVE_REPORTED and CALLER_ID_PASSTHROUGH_REPORTED: technical reports, NOT proven connected/payable calls
- LANDING_VISUAL_APPROVED_REPORTED: reported page visual approval, NOT live traffic permission
- RECORDING_ENABLED_REPORTED and RECORDING_DISABLED_REPORTED: claimed recording state, NOT legal compliance proof
- BUYER_INTERNAL_DECISION_PENDING_REPORTED: decision pending, NOT buying approval
- ROOFING_BUYER_REVISED_COMMERCIAL_TERMS_REPORTED: negotiation/reporting, NOT a signed contract
- PUBLISHER_SPONSORED_PLACEMENTS_ONLY_REPORTED: NEGATIVE commercial fit, not a buyer
- TEST_ENDED_BEFORE_CONNECTION_REPORTED: unsuccessful test, NOT payable call delivery
- PILOT_TECHNICAL_REQUIREMENTS_SENT and COMPLETE_BUYER_REQUIREMENTS_SENT: outbound requests from Empire AI, NOT incoming buyer claims

One previously observed partner's express deferral until established traffic exists is NOT represented by those original eleven event codes. No new negative semantic code has been invented. The existing Conversation OS / Buyer Acquisition owner must review any new first-party code and issuer authority separately.
