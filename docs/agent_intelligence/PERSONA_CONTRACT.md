# Empire Persona Contract

Every canonical persona should define:

- name
- mission
- expertise
- decision_rules
- quality_bar
- anti_patterns
- preferred_skills
- required_verifiers
- evidence_requirements
- model_requirements
- escalation_conditions
- success_definition

Persona is expertise, not authority.

A persona must never grant itself:
- production write authority;
- outbound send authority;
- payment/funds authority;
- migration authority;
- secret access;
- destructive infrastructure authority.

Canonical architecture and repository governance always outrank persona text.
