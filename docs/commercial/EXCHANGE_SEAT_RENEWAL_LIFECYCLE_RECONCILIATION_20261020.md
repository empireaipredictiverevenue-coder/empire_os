# Empire AI Exchange — monthly seat renewal and operator readback

20 October 2026. Isolated branch: feature/exchange-fulfilment-mrr-review-20261020.

## Built in this change

- empire_os/exchange_seat_renewal_lifecycle_v1.py — read-only per-membership renewal-cycle reconciliation.
- scripts/review_exchange_self_serve_fulfilment_mrr_20261020.py — optional private renewal input to the existing read-only Exchange operator report.
- Tests: tests/test_exchange_seat_renewal_lifecycle_v1_20261020.py and tests/test_exchange_renewal_operator_cli_20261020.py.

This is an **offline evidence contract**, NOT a canonical database reader, subscription writer, invoice creator, billing daemon, customer access gateway or MRR ledger.

The lifecycle uses original calendar billing-anchor dates rather than fixed 30-day periods; Jan 31 → Feb 28/29 → Mar 31. It checks up to 24 bounded periods and refuses duplicate cycle indices, reuse of invoice IDs/payment request IDs/payment receipt IDs, cross-buyer/tenant membership mismatches, unsupported plan or price, contract SHA drift, missing previous history, invalid statuses and malformed inputs.

The candidate state makes nonpayment, missed current month, refunded/reversed payment, cancellation effective date and suspension visible as **no access**. A 'settled_shape' synthetic month is labelled PAID_RECEIPT_SHAPE_REVIEW_REQUIRED, not a verified customer payment or activation.

The next period's idempotency digest is a **preview only**; there is no invoice sent, USDT auto-debit, backend entitlement transition, CRM write or customer contact.

### Owner-private renewal input (OPTIONAL)

The new operator command can accept a local JSON file containing keys membership and periods, with *owner-controlled synthetic or independently sourced* receipt shapes. The file must exist, must not be a symlink, must be at most 1MB, and must have owner-only permissions (0600 or stricter). It is never generated by a public caller or stored in Git. The operator prints no buyer IDs, names, personal emails, wallet addresses, source raw data or transaction hashes.

Example **no private input** (this is the production-safe current state):

    cd /home/ubuntu/empire_worktrees/exchange_fulfilment_mrr_review_20261020
    PYTHONPATH=. /srv/empire_os/.venv/bin/python -B -m scripts.review_exchange_self_serve_fulfilment_mrr_20261020 --read-only

This reports private_renewal_review.state=NO_AUTHENTICATED_RENEWAL_OWNER_SOURCE_ATTACHED.

With an approved private owner input, append:

    --private-renewal-cycles-file /path/to/private/finance_owner_reconciled_cycles.json

Even correctly shaped receipt data is **not independently authenticated by this process** and never activates seats or recognizes any MRR.
