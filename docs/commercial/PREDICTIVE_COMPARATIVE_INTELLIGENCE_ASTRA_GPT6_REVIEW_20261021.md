## Per-tier buyer-visible scope and price justification audit
1. **Diagnostic $25k**: evidence and revenue-leakage assessment, data lineage, forecast-readiness, scoped action report. Requires prospect-specific access rights, source inventory, true delivery workload/cost, documented deliverables and a buyer willing to pay. Do not promise discovered revenue.
2. **Command Center $50k starting**: tenant-restricted CRM/Finance ingestion, documented integrations, read-only revenue cockpit, operational and forecast caveats. Requires exact integrations and SLAs, access controls, data migrations and support costing.
3. **Intelligence OS $100k starting**: cross-department evidence, prospective original predictions, authentic outcome matching, baseline evaluation and Economic Memory. Do not price as commercially proven forecasting while calibrated customer cohorts remain absent.
4. **Autonomous OS $200k starting**: above plus governed next-best-action agent workflow, audit, human gates, suppression controls, error recovery and measured run costs. Product tier does not grant autonomous customer contact, spend, terms or money movement.
5. **Private Strategic $250k+**: custom tenant isolation, enterprise model custody, private feeds, incident and DR planning, white-label, contract and data boundaries; never claim security/compliance/SLA certification until independently accepted.

Proof required FOR EACH SKU: customer-specified problem, scoped statement of work, measured delivery labour, realistic compute/support and licence costs, external third-party charge obligations, security/SLA commitments, signed price/terms, comparable *total* contract costs, verified customer acceptance and observed value or ROI. A lower-feature SaaS seat price is not enough to reject a bespoke floor; likewise a high bespoke implementation fee is not proven justified because the product has many source modules.

## ASTRA using ChatGPT GPT-6: independent challenge specification
Input: exact immutable release SHA/manifest, full test outputs, original 86-SKU catalogue comparison, founder-approved five prices, official comparator URLs/as-of dates, current Cloud + Intelligence snapshots, tenant source admission results, anonymized original evidence (when present), operating cost ledger, customer acceptance and delivery/SLAs when independently available. **Independence requires a separate review invocation**; the producing assistant must not mark its own work `INDEPENDENTLY_APPROVED`.

Review:
1. Re-run pinned build and adversarial tests; find look-ahead leakage, replay nondeterminism, forged tenant/source claims, late backfills, duplicate events and negative/cross-currency prices.
2. Reconcile each SKU to original data-rights, product functionality, observed acceptance, binding terms, currency and billing unit. Flag absent competition evidence versus actual tested feature parity.
3. Demand original measured labour, licence/API/storage/inference and support costs and customer willingness-to-pay/benefit. Run downside/base/upside sensitivity **on authenticated or explicitly labelled assumptions**; no invented ROI.
4. Verify model custody, calendar/forecast uncertainty, cohort bias, sampling thresholds, censored outcomes, independent settlement proof, source freshness, fair-use and cross-tenant isolation.
5. Assess Cloud control/data/compute/serving plane entitlements, service health versus scientific readiness, canary/rollback, error budgets and privacy security review.
6. Return severity-ranked defects, exact failing test and patch proposal; mark each SKU `JUSTIFIED_WITH_EVIDENCE`, `RESEARCH_ONLY`, `PRICE_REVIEW_REQUIRED` or `NOT_ENOUGH_DATA` from independently verified evidence.
7. Never authorise repricing, new public promise, tenant customer activation, model training, external outreach, payments, or DDL. Founder reviews and separately approves exact release changes after retests.
