## What is implemented

The WordPress **empire-yard-atelier** child theme now contains two clearly distinct visual modes inside its ORIGINAL React / Three Fiber showroom:

- **Original concept:** previous small procedural car; still renders first on desktop and when a mobile visitor expressly selects “Explore in 3D”. No third-party GLB required.
- **Studio PBR:** a separate high-detail, third-party glTF vehicle imported by React.lazy and Drei useGLTF **only after explicit “Load Studio PBR · 9 MB” interaction**. The GLB stays on the same WordPress child-theme origin. Camera angle selectors, paint presets, accessible pressed states and studio attribution remain within the existing WordPress theme. Three.js OrbitControls allows drag and bounded zoom. Pressing “Original concept” restores the first mode.

A local one-time procedural `RoomEnvironment` plus PMREM studio softboxes gives metallic/clearcoat body materials local environment reflections **without external HDRI/CDN fetching**. To protect less powerful browsers, Studio mode renders `frameloop="demand"`, fixed pixel ratio 1, with contact shadows and heavyweight continuous animation disabled. PBR textures and model geometry are preserved; expensive transmission and iridescence material features are disabled for the on-demand website view. Mobile retains the existing separate opt-in gate before any WebGL is started.

**The 3D model is NOT generated by Empire AI, a real client's car, or commercial inventory.** It is an editorial technical sample integrated for capability demonstration.
