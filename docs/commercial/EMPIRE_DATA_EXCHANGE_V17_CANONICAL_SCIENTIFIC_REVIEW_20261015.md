# Data Exchange V17 — Canonical Scientific Evidence Review

**One existing sovereign EmpireDB. No new database, timer, service, agent or
model.** This is an opt-in extension of the already-deployed root-only
V16 read-only inspector, reusing the V15 canonical custody and V14 Signal
Board and the existing AGI research bridge.

## Evidence boundaries

- A single persisted observation establishes only a locally validated,
  append-only observation. It cannot establish a source field transition,
  project initiation, buyer intent, predictive accuracy or revenue.
- Two time-separated, custody-validated observations may establish
  descriptive SOURCE FIELD changes in the selected three-record pilot,
  never a full regional market census, construction commencement or
  commercial demand.
- The experimental control set identifies sampled entities whose
  **monitored fields stayed the same** between the latest two observations.
  It is not a randomized, independent causal negative-control cohort.
- A government GET that matches canonical custody is SAME-SOURCE
  corroboration, not government-authenticated source revision history.
- The output stays HOLD unless two valid observations exist, they
  are separated by at least 24 hours, the latest observation is timely,
  the new public-source recheck matches, and V14 comparisons are not held.
- A rolling last-16-observation read window that excludes genesis is not
  a full-history proof; the existing AGI bridge is held in that case.
- The AGI bridge runs only on compatible canonical history and creates
  **no actual model inference** or external actions. It emits existing
  hypothesis-review workstreams without granting execution authority.
- Forecast calibration, verified outcomes, dataset-specific source-field
  licensing, independent provenance, buyer interest, distribution, money,
  outbound and commercial claims remain blocked.

## Run the new review

The V17 functionality extends the EXISTING V16 operator:
`scripts.inspect_data_exchange_v16_live`.

Use the authorised production root shell to perform the same read-only
canonical inspection with both fresh official recheck and the scientific
evidence packet:

```bash
sudo -n bash -c '
cd /srv/empire_os
./.venv/bin/python -m scripts.inspect_data_exchange_v16_live \
  --read-only --recheck-official --scientific-review
'
```

The command reads the dedicated protected credential internally through
the reviewed V15 reader. No secrets are printed. It creates no migrations,
does not write a second observation and does not enable any services.
