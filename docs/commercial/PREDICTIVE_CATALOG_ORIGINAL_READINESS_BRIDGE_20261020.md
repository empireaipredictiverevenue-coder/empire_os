- `empire_os/predictive_catalog_readiness_bridge.py`: compares the complete original snapshot against the existing canonical `assess_catalog_item` policy, checks aggregate active/terms/blocker counts and flagship approved entry prices, and emits per-SKU blockers and next original owner action.
- `scripts/review_predictive_catalog_readiness_20261020.py --read-only`: fixed local snapshot reader; concise summary by default or `--all-products` for all current SKU contracts. Held sources yield a structured fail-closed status and nonzero exit; no traceback or private customer identifiers are returned.
- `empire-predictive-observe catalog`: pinned read-only launcher command; run it only after immutable release preparation/checksum proof. No new service/timer or production checkout dependency.
