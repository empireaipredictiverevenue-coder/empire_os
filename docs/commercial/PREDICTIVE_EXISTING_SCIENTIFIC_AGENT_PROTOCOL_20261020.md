## Scientific product integration

- `empire_os/predictive_product_scientific_agent_review.py` reuses the **existing scientific agent's six pinned skill digests and evidence protocol** via the release-local, source-hash checked `predictive_existing_scientific_agent_skill_lock.py` and the existing tracked `ExperimentRegistryRecord` interface. The original AGI agent code is **untracked in the production owner's checkout** and deliberately not imported from mutable production by the immutable Predictive Revenue release; this adapter does not reimplement its world-model algorithm or invoke that agent's inference.
- Product-science preregistration protocol is code-pinned, with a SHA-256 integrity marker but **no original registry submission**. Hypothesis: for the same tenant and canonical product version, a forecast issued before its outcome should improve Brier loss over the historical baseline based only on prior AVAILABLE outcomes. Minimum 20 distinct resolved past outcomes and 12 true out-of-sample prediction/outcome evaluations.
- Existing per-product evaluator `predictive_product_scientific_holdout.py` supplies optional synthetic/externally-supplied Brier review. The scientific adapter treats all supplied statistics as **unauthenticated until the original owner verifies issuer, immutable pre-outcome forecast registration, same-tenant cohort and ledger outcomes**. Impossible or contradictory counts, Brier and claimed skill are held.
- Scientific review returns methodological blockers, not automatic enterprise eligibility: missing original paired outcomes, immutable registry evidence, independently held-out source population, calibration gap and model-vs-baseline underperformance are all separate.
- `empire-predictive-observe science-agent` performs a **one-shot protocol and skill integrity review only**, using the existing fresh read-only catalogue and predictive intelligence snapshots. It does **not run the agent's AGI world-model experiment**, train a model, collect customer data, register a scientific experiment, start automatic agent inference, request an Astra review or activate products.
- One-shot existing AGI science benchmark was run separately to confirm agent functionality; its observations cannot be connected as actual Predictive Revenue outcomes. No conflation.
